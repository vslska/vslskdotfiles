# Arch Linux + Niri Dotfiles (ThinkPad P14s Workspace)

Welcome to my personal, highly customized, and optimized Linux development ecosystem. This repository contains my declarative configuration files (dotfiles) for a rock-solid, fast, and minimal environment built around **Arch Linux** and the **Niri** WM.

## Hardware & System Architecture
* **Machine:** Lenovo ThinkPad P14s Gen 6 AMD
* **CPU:** AMD Ryzen™ AI 9 HX PRO 370 (12 Cores / 24 Threads, up to 5.10 GHz)
* **RAM:** 64GB DDR5 @ 5600MT/s
* **GPU:** Integrated AMD Radeon™ 890M (RDNA™ 3.5)
* **Storage:** 1TB M.2 PCIe Gen4 Performance NVMe SSD
* **OS:** Arch Linux (Rolling Release)

## Core Environment Stack
* **WM** `Niri`
* **Terminal shell:** `Fish Shell`
* **Desktop shell:** `Noctalia Shell`
* **Terminal Emulator:** `Kitty`
* **File Manager:** `Yazi`
